# 第一章 緒論

## 1.1 研究背景

軟體定義網路（Software-Defined Networking, SDN）將控制邏輯集中到控制器，交換機只負責根據規則轉送封包。這個架構讓網路行為變得可程式化，但也讓攻擊的影響更集中——控制器本身就是高價值目標，而交換機有限的 flow table 容量容易被攻擊者利用。

網路安全領域一直有個核心難題：要在高速流量中即時發現攻擊，又不能花太多資源在監控本身。傳統的深度封包檢測（DPI）逐封包檢查、逐特徵比對，在 SDN 的線速環境中成本太高。機器學習方法能自動學習攻擊模式，但需要大量標記資料，且黑箱決策難以在資安場景中被信任——管理者需要知道「為什麼判定這是攻擊」。

網路量測領域有一類輕量級資料結構，稱為 Sketch。Sketch 以犧牲微小精確度為代價，將高速封包流壓縮成極小的統計摘要，適合部署在資源受限的交換機上。Count-Min Sketch 估計頻率分佈、Elastic Sketch 追蹤 heavy hitter 同時計算熵值、UnivMon 從單一結構派生多種查詢——這些 Sketch 各自專精於不同的量測任務。

一個自然的問題出現了：能不能利用多個 Sketch 各自捕捉的流量特徵，來識別正在發生的攻擊類型？

## 1.2 問題陳述

現有的 Sketch-based 攻擊檢測方法幾乎都使用**單一 Sketch**：有人用 CM Sketch 追蹤 flow 大小變化來抓 DDoS，有人用 Elastic Sketch 的熵值來判斷流量是否異常。這些方法能回答「有沒有攻擊」，但很難回答「是什麼攻擊」。

問題的本質不是「哪個 Sketch 不夠好」，而是**單一 Sketch 的測量能力有限**。以 Elastic Sketch 為例：它很擅長追蹤 elephant flow 和計算流量分佈，但要區分 Port Scan（大量短 flow）和 DDoS（少數 heavy flow），光靠分佈資訊不夠——你需要同時知道 flow 的生命週期、來源的集中度、埠號的變異模式。這些資訊分散在不同的 Sketch 的設計目標中。

更具體地說：

1. **不同攻擊在不同量測維度上留下足跡。** DDoS 改變的是 flow 大小分佈和來源集中度，Port Scan 改變的是埠號變異度和 flow 存活時間。單一 Sketch 只能覆蓋其中一部分。

2. **互補性未被利用。** CM Sketch 擅長頻率估計但無法處理 heavy hitter、Elastic Sketch 能分離 elephant/mouse flow 但不擅長學習型適應、UCL-Sketch 能用極少記憶體達到高精度頻率估計。如果讓這些 Sketch 同時運行，它們捕捉到的流量特徵是互補的——把這些特徵合起來看，資訊量遠大於任何單一 Sketch。

3. **缺乏系統性的組合框架。** 目前沒有人回答：給定一組攻擊類型和一組可用的 Sketch，應該怎麼選擇、怎麼組合、怎麼從組合特徵中做出分類決策？

## 1.3 研究動機與目標

本研究嘗試建立一個**多 Sketch 協同**的攻擊檢測框架。核心想法是：不依賴任何單一 Sketch 的完美性，而是讓多個 Sketch 各自做自己擅長的事，再把它們產出的特徵彙整成一個資訊豐富的向量，用來同時檢測攻擊並分類攻擊類型。

這個想法受到兩個觀察的啟發。第一，教授在方向討論中指出：「針對熵值其實也沒什麼好優化的。應該是找一些通用的網路測量 sketch，來去針對不同的攻擊做識別。」重點不在於改良某個 Sketch 的計算精度，而在於如何善用現有 Sketch 的多樣性。第二，文獻中反覆出現一個訊號：不同攻擊需要不同的特徵才能有效區分——Nychis et al. (2008) 證明單一維度熵值無法覆蓋所有異常類型，FP-Sketch (2025) 顯示不同流量模式需要不同設計策略的 Sketch。

本研究具體目標：

1. **建立多 Sketch 特徵抽取架構**：選定一組互補的通用網路量測 Sketch（CM Sketch、Elastic Sketch、UnivMon、UCL-Sketch），在 SDN 交換機上並行部署，每個 Sketch 產出其所擅長的特徵維度。

2. **設計特徵融合與攻擊分類方法**：將多個 Sketch 的輸出整合為一個聯合特徵向量（包含頻率、熵值、cardinality、heavy hitter 資訊等），基於不同攻擊在聯合特徵空間中的分佈差異進行分類。

3. **實驗驗證多 Sketch 協同的效果**：比較單一 Sketch 與多 Sketch 組合在攻擊檢測率和分類準確率上的差異，量化「協同」帶來的增益。

## 1.4 研究貢獻

1. **多 Sketch 協同框架**：提出一個系統性的方法來選擇、部署和組合多個互補的網路量測 Sketch，用於 SDN 環境中的攻擊檢測。框架的核心在於「讓每個 Sketch 做自己擅長的事」，而非試圖用單一 Sketch 包辦所有任務。

2. **聯合特徵空間的攻擊分類**：定義一個跨 Sketch 的聯合特徵向量，包含頻率分佈（CM Sketch）、熵值與 heavy hitter（Elastic Sketch）、通用流量摘要（UnivMon）、學習型頻率估計（UCL-Sketch）等多元資訊。基於此聯合特徵空間設計可解釋的分類規則。

3. **Sketch 選擇策略的實證分析**：透過系統性的消融實驗，量化每個 Sketch 對不同攻擊類型的貢獻，給出「哪種攻擊最需要哪個 Sketch 的特徵」的實證答案。

## 1.5 論文架構

第二章回顧三個領域的文獻：SDN 攻擊檢測方法的演進、多種通用網路量測 Sketch 的設計原理與適用場景、以及多特徵融合在攻擊分類中的應用。

第三章描述多 Sketch 協同框架的設計：Sketch 的選擇策略、並行部署架構、聯合特徵向量的組成、以及基於聯合特徵的攻擊分類邏輯。

第四章為實驗設計與結果分析，在 Mininet 模擬的 SDN 環境中比較不同 Sketch 組合的檢測與分類效能。

第五章總結研究成果、討論框架的限制與未來可延伸的方向。
